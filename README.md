\#Smash Burger Bar - Sitio Web Oficial



Este proyecto fue desarrollado con el objetivo de optimizar la presencia digital del local, ofreciendo una experiencia de usuario fluida, atractiva y rápida para conocer el menú, las sucursales y facilitar el contacto.



\*\*\[Ver sitio web en vivo](https://laranothardt.github.io/restaurante-sbb/)\*\*



\---



\##Características del Proyecto



\- Interfaz adaptada para dispositivos móviles, tablets y pantallas de escritorio.

\- Sección dinámica y visualmente atractiva para explorar los productos, combos y promociones.

\- Identidad Visual Consistente, aplicación cuidada de la paleta de colores, tipografías y el branding propio de la marca.

\- Estructura limpia y optimizada utilizando las mejores prácticas de desarrollo web.



\##Tecnologías Utilizadas



Las herramientas y lenguajes empleados en el desarrollo de este sitio son:



\- \*\*HTML5\*\* - Estructuración semántica y accesible del contenido.

\- \*\*CSS3\*\* - Estilos personalizados, diseño adaptativo con Flexbox/Grid y efectos visuales.

\- \*\*JavaScript (ES6)\*\* - Interactividad, manejo del menú desplegable y dinamismo en la navegación.

\- \*\*Git \& GitHub\*\* - Control de versiones y despliegue automatizado.
